# Проект «Сложно сосредоточиться»

> Учебный проект, выполненный в рамках курса «Фронтенд-разработчик» от Яндекс Практикума по адаптивной вёрстке сайта с двумя цветовыми темами.

### Задача проекта:
- Создать HTML-разметку и оформить страницу по макетам для мобильных устройств, планшетов и компьютеров.
- Построить адаптивную вёрстку по подходу Mobile First.
- Подготовить светлое и тёмное оформление, связав CSS с готовым скриптом переключения тем.

## Описание проекта
**«Сложно сосредоточиться»** — сайт-статья о том, почему нам трудно удерживать внимание и что помогает вернуть фокус. Материал объединяет объяснения, практические советы и иллюстрации, а оформление включает дневную и неоновую цветовые схемы.

Скрипт переключения тем предоставлен в заготовке. Моя работа — разметка, стилизация и адаптация страницы.

## Реализовала:
- Создала структуру страницы с заголовками, тематическими разделами, галереей и подвалом.
- Построила мобильную версию и добавила медиазапросы для экранов от 768 и 1024 пикселей.
- Настроила расположение элементов с помощью CSS Grid и Flexbox.
- Реализовала галерею, которая перестраивается из одной колонки в сетку с изображениями разного размера.
- Настроила плавное изменение размеров крупных заголовков через `clamp()`.
- Вынесла цвета, шрифты и параметры оформления в CSS-переменные.
- Подготовила отдельные стили светлой и тёмной тем.
- Оформила фон страницы, декоративные элементы и текстовые акценты.
- Стилизовала кнопки выбора темы и ссылки, включая состояния наведения и клавиатурного фокуса.

## Результат:
- Научилась разрабатывать адаптивную страницу по подходу Mobile First, постепенно усложняя расположение блоков для больших экранов.
- Закрепила работу с CSS Grid и Flexbox, медиазапросами и гибкими размерами.
- Освоила организацию цветовых схем через переопределение CSS-переменных.
- Разобралась во взаимодействии каскада, селекторов и системных предпочтений при оформлении тем.
- Научилась адаптировать композицию и типографику под разные размеры экрана, сохраняя общий стиль страницы.

### Структура проекта

```text
.
├── index.html               # разметка страницы
├── fonts/                   # шрифты и fonts.css
├── images/                  # иллюстрации, фоны и иконки
├── scripts/
│   └── script.js            # готовый скрипт переключения тем
├── styles/
│   ├── globals.css          # сброс и общие стили
│   ├── variables.css        # CSS-переменные
│   ├── style.css            # оформление и адаптивная вёрстка
│   ├── light.css            # стили светлой темы
│   └── dark.css             # стили тёмной темы
└── README.md                # документация проекта
```


## Запуск

Откройте `index.html` в браузере или запустите страницу через Live Server в редакторе кода.
