# Сложно сосредоточиться

**Сложно сосредоточиться** — адаптивный сайт-статья о внимании и причинах, по которым нам бывает трудно удерживать фокус.

## Технологический стек:

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

## Основной функционал:
- Статья о концентрации, отвлекающих факторах и способах удерживать внимание.
- Адаптивная вёрстка для мобильных устройств, планшетов и компьютеров.
- Галерея изображений с изменением расположения в зависимости от ширины экрана.
- Меню оформления «День», «Авто» и «Неон» с сохранением выбора.
- Состояния наведения и клавиатурного фокуса для ссылок и кнопок.

## Реализация:
- Страница построена на семантической HTML-разметке.
- Для расположения элементов используются CSS Grid и Flexbox.
- Адаптивность реализована через медиазапросы и функцию `clamp()`.
- Цвета и параметры оформления вынесены в CSS-переменные, темы — в отдельные файлы.
- JavaScript переключает классы оформления и сохраняет выбранный режим в `localStorage`.
- Шрифт IBM Plex Mono подключён локально через `@font-face`.

## Запуск

Откройте `index.html` в браузере или запустите страницу через Live Server в редакторе кода.

Установка зависимостей и сборка не требуются.
